# NAN2026-Project

AI 에이전트와 함께 개발하는 Unity 게임 프로젝트입니다. 현재는 Unity 프로젝트의 초기 구성이 완료된 단계입니다.

## 개발 환경

- Unity `6000.3.13f1`
- Universal Render Pipeline (URP) `17.3.0`
- Input System `1.19.0`

Unity Hub에서 저장소의 루트 폴더를 열어 실행합니다. 패키지는 `Packages/manifest.json`을 기준으로 Unity가 자동으로 복원합니다.

## 저장소 구성

- `Assets/`: 게임 코드, 씬, 프리팹 및 에셋
- `Packages/`: Unity 패키지 의존성
- `ProjectSettings/`: 프로젝트 공용 설정
- `AGENTS.md`: AI 에이전트가 작업 전에 따라야 할 저장소 지침

`Library/`, `Temp/`, `Logs/`, `UserSettings/`와 IDE가 생성하는 프로젝트 파일은 커밋하지 않습니다.

## AI 협업 원칙

이 프로젝트의 구현과 Git 작업은 AI 에이전트를 통해 진행합니다. 모든 AI 에이전트는 작업을 시작하기 전에 루트의 [`AGENTS.md`](./AGENTS.md)를 읽고 다음 원칙을 지켜야 합니다.

1. 요청 범위와 기존 변경 사항을 먼저 확인합니다.
2. Unity 에셋과 대응하는 `.meta` 파일을 함께 관리합니다.
3. 변경 목적에 맞는 검증을 수행한 뒤 결과를 보고합니다.
4. 아래 커밋 컨벤션에 맞춰 하나의 목적 단위로 커밋합니다.

## 커밋 컨벤션

커밋 제목은 `<이모지>[<라벨>] <요약>` 형식을 사용합니다. 요약은 변경 목적이 드러나는 짧은 한국어 명령형 문장으로 작성하고, 마침표는 붙이지 않습니다.

예시: `✨[Feat] 플레이어 점프 기능 추가`

| 라벨 | 사용 기준 | 제목 및 본문 작성 기준 |
| --- | --- | --- |
| ✨`[Feat]` | 새로운 게임 시스템, 메카닉, 콘텐츠 추가 | 제목에 기능 설명 |
| ⚙️`[Core]` | 백엔드, 프레임워크, 도구, 시스템 기반 작업 | 제목에 기능 설명 |
| 🐛`[Fix]` | 명백한 버그 또는 기획 의도와 다른 동작 수정 | 제목에 현상, 본문에 수정 방법 |
| ♻️`[Refactor]` | 기능 변경 없는 코드 구조 개선 | 제목을 `~ 구조 개선` 형태로 작성 |
| 🗺️`[Design]` | 레벨 디자인, 밸런싱, 수치 조정 | 제목에 현상, 본문에 조정 방법 |
| 🩹`[Patch]` | 사소한 프리팹·씬 변경, 오타 수정, 단순 수치 조정 | 제목에 현상, 본문에 수정 방법 |
| 🗃️`[Update]` | 데이터베이스 관련 업데이트 | 변경한 데이터와 목적 설명 |
| 🎨`[Asset]` | 비주얼 에셋, 사운드, 애니메이션 추가 및 수정 | 대상 에셋 설명 |
| 📝`[Docs]` | README, 기획서, 주석 등 문서 수정 | 대상 문서와 목적 설명 |
| 🧹`[Chore]` | 빌드 설정, 패키지 관리, Git 설정, 파일 이동, 폴더 구조 변경 | 유지보수 작업 설명 |
| 🔀`[Merge]` | 브랜치 병합 | 병합 대상 설명 |
| 🔥`[Del]` | 기능 제거 | 제거 대상 설명 |
| 🎉`[Init]` | 프로젝트 초기 구성 | 초기화한 범위 설명 |
| 💚`[Build]` | 빌드 파일 생성 | 제목에 버전 표기 |

변경에 대한 추가 맥락이 필요하면 제목 다음 빈 줄부터 본문을 작성합니다. 본문에는 무엇을 왜 바꿨는지, 검증하지 못한 항목이 있다면 그 이유를 기록합니다.
